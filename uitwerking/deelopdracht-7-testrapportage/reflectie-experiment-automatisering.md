# Reflectie — Experiment automatisering met Claude Code

## Wat heb ik gedaan?

TC-001 en TC-002 volledig geautomatiseerd uitgevoerd met behulp van Claude Code en Playwright. Claude Code heeft de testscripts geschreven, uitgevoerd en de rapportage aangelegd op basis van de testresultaten.

## Wat werkte?

De automatisering werkt. TC-001 en TC-002 draaien zonder handmatige stappen en de resultaten landen direct in de rapportage.

## Wat vond ik er niet goed aan?

De gegenereerde testscripts zijn rommelig: rapportageteksten zijn verweven met testlogica, en de structuur is niet schaalbaar voor de rest van de testcases. Dit is niet hoe ik de overige testen wil aanpakken.

## Hoe wil ik verder?

Ik wil nog uitzoeken hoe ik automatisch screenshots als bewijs kan toevoegen aan de rapportage. Daarna bepaal ik hoe ik de rest van de testen aanpak.
